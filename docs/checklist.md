# Hackathon Checklist

---

## Process

- [ ] Conduct user interviews (corridor, 2-3 people minimum)
- [ ] Document interview findings in docs/research/interviews.md
- [ ] Update user-snapshot.md after interviews
- [ ] Validate or invalidate hypotheses in docs/hypotheses.md
- [ ] Document every meaningful decision in DECISIONS.md

---

## Iterations (jury evaluates this)

For each iteration:
- [ ] Screenshot before
- [ ] Screenshot after
- [ ] Entry in docs/changelog.md — what changed + why

---

## Product

- [ ] Focused on ONE concrete first action (not multiple scenarios)
- [ ] Uses Material UI component library
- [ ] Uses DataArt Figma icon set
- [ ] Deployed on Vercel — public link works

---

## Presentation (2 June)

- [ ] Problem Statement
- [ ] UX Hypothesis
- [ ] User Flow
- [ ] Live prototype demo (public link)
- [ ] Technologies & Tools — how AI was used specifically
- [ ] Iteration Journey — screenshots, decisions, confirmed/rejected hypotheses, corridor testing insights

---

## Sanity checks

- [ ] Solution is NOT a generic to-do list with AI
- [ ] Solution focuses on the moment of friction, not motivation
- [ ] Interface is simple — not trying to solve too many scenarios
- [ ] Can answer: "Why hasn't the user acted yet — and how does our solution change that?"
