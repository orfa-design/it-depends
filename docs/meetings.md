**Механіки утримання (brainstorm):**

- Обмежені токени — як ліміти в Figma/Claude Code, організовує поведінку

- Реферальна механіка — запрошуєш колегу → отримуєш доступ до складніших фіч
- Гейміфікація — ігрові монети за шерінг → купуєш розбивку на підзадачі

**Рекомендація тулів:**
Продукт може рекомендувати різні AI інструменти під різні частини задачі (Claude Code → код, Midjourney → графіка, Perplexity → ресерч) — як курований контент.
