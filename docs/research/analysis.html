Що ми знаємо,
що assumed, і що змінилось

Survey data (11 відповідей) проти наших assumptions. Самокритика competitor analysis. Що це означає для продукту.

TL;DR — 3 речі
1.H2 (meta-paralysis "не знаю з чого почати") не підтверджується: 0% обрали це як бар'єр. Реальна проблема — casual→power user transition, не вхід в AI.
2.H4 (work-adjacent idea) підтверджується повністю: 100% назвали конкретні pain points. Документація, дизайн-система, прототипування домінують.
3."Готовий промпт" має сильний сигнал: 90% позитивно/можливо. Але "залежить від задачі" = потрібна контекстність, не universal prompt.

Секція 02

Assumptions Audit — оновлені статуси

13 assumptions до і після даних. Жирним — ті що змінились.

# Assumption Було Зараз Evidence
U1 Meta-level paralysis — не знає з чого починати з AI як явищем 🔴 draft ❌ не підтв. 0% обрали "не знаю з чого почати" як бар'єр. Sample biased.
U2 Соціальний тригер — побачила колегу → paralysis 🔴 draft 🟡 частково 6/11 (55%) обрали. Реальний, але #2, а не primary. Curiosity = #1 (82%).
U3 Поточне рішення Оксани = нічого (paralysis) 🔴 draft ❌ невірно 0 "ніколи не пробувала". Всі вже в AI. 27% комфортно — не наш юзер взагалі.
U4 Work-adjacent idea — є конкретна незручність в роботі 🔴 draft ✅ підтверд. 100% назвали конкретні pain points. Ніхто не сказав "не знаю". H4 — confirmed.
U5 Оксана впізнає себе в stories (Аня, Маша...) 🟡 draft ? невід. Не тестувалось прямо. Потребує corridor test з /calibrate.
U6 Оксана повернеться після off-app кроку 🔴 draft ❌ не знаємо Не тестувалось. Найбільша діра в flow.
P1 Готовий промпт знижує blank slate 🔴 draft ✅ підтверд. 90% позитивно/можливо. "Залежить від задачі" = треба контекстність.
P2 Artifact-first output створює ownership ("моє") 🔴 draft ? невід. Воркшоп-ефект (7/8 продовжили) — непряме підтвердження H3.
P3 /calibrate stories кращі за /start task selection 🟡 нова ? невід. Нова гіпотеза від Люди. Потребує A/B або corridor test.
P5 Оксана не закриє продукт між промптом і поверненням 🔴 критич. ❌ не знаємо Найбільша UX діра. Жодних даних.
C1 DataArt дизайнери репрезентативні для всіх mid-level 🟡 вибір 🟡 proxy ok Pain points (Q4) виглядають universal. Прийнятно як proxy.
C2 Проблема існує в масштабі 🟢 очікув. ✅ підтверд. Всі мають pain points. Survey підтверджує наявність ринку.
C3 Продукт диференційований від "просто Claude" 🟡 позиц. 🟡 умовно Контекстний промпт + designer framing диференціює. Але слабкий moat.
💡
Головний зсув після даних
Наш юзер — не людина яка ще не почала з AI, а людина яка вже в chat-рівні і хоче більше. Вона застрягла не до AI, а всередині нього — на переході від "питати" до "будувати". Це підтверджує pivot casual→power user який Люда зафіксувала ще 24 травня.
Секція 03

Самокритика competitor analysis

Що в першій версії було занадто впевнено або неправильно.

🚫
"Prompt generator without analog" — невірно
Custom GPTs, Lovable onboarding, v0 templates, Anthropic Console — всі дають prompt scaffolding. Наш реальний angle вужчий: artifact-first prompts куровані під designer pain. І навіть це не moat — це позиціонування.
🚫
Strava/Slack mechanic — wishful thinking
Соціальний тригер асиметричний: Оксана хоче бачити колег, але не хоче бути побаченою на цьому етапі. Symmetric share-mechanic може ламати core moment. Поточний /start без примусового share — правильний компроміс.
🚫
Off-app step — найбільша UX діра
"Скопіюй в Claude Code → повернись тиснути 'Зробила'" — кожен off-app step це нова ймовірність не повернутись. Питання яке зруйнує pitch: "А чому не зайти одразу в v0?" Треба готову відповідь.
⚠️
Habit loop — поза брифом
Бриф — про first action (intent → action), не recurring action. Habit metrics журі не бачить. Оптимізуємо для session 1, хвилина 5, перша дія.

Пропущені конкуренти які варто знати:

Custom GPTs / GPT StoreПрямий конкурент
Сотні тисяч guided AI experiences, мільйони MAU. Безкоштовно для ChatGPT Plus. Наш gap — designer-specific curation + artifact framing.
Replit AgentСтруктурна загроза
Робить ВСЕ in-app, без off-app переходу. Наш найгірший конкурент по UX continuity.
YouTube / TikTok AI tutorialsНевидимий
Реальний first stop для "як почати з AI". Безкоштовно, нескінченно. 45% наших survey respondents перед продуктом дивляться саме це.

Секція 05

Ключове рішення після даних

Дані змінюють хто наш юзер. Є два варіанти відповіді.

Хто насправді Оксана?

Варіант А — Зберегти original framing
Визнати що sample biased. Наша "Оксана з meta-paralysis" просто не взяла опитування — вона не настільки engaged. Продовжуємо з original framing, але змінюємо бар'єр з "paralysis до відкриття AI" на "confusion у виборі інструментів". Слабша позиція для журі — потребує "але наша target не в sample."
Варіант Б — Pivot до даних (рекомендовано)
Прийняти що юзер — casual→power user. "Я вже в Claude, але хочу будувати речі для своєї роботи, а не просто питати." Змінити product framing відповідно. Сильніша позиція: підкріплена даними, /calibrate stories (Аня, Маша) вже показують це, H4 (конкретні pain points) підтверджується на 100%.
Що це означає для продукту при Варіанті Б:
— User moment: не "вперше відкрила AI", а "хочу AI для своєї дизайн-роботи, але не знаю як почати з конкретного"
— /calibrate stories показують "що роблять дизайнери як ти" — пряме рішення
— Pain point templates (документація, дизайн-система) = core product, не training wheels
— Prompt generator = спосіб перейти від "знаю що хочу" до "знаю що написати"
Секція 06

Відкриті питання — для дзвінку з Людою

1.
/calibrate vs /start — який є продуктом?
Зараз два flow без чіткого "переможця". Яке веде з лендінгу? Журі побачить роздвоєння.
2.
Off-app повернення — що робимо?
Найбільша діра. Чи є що зробити за 6 днів? Або приймаємо як обмеження PoC і готуємо відповідь для журі?
3.
Prompt customization ("Моя задача") — беремо до дедлайну?
Ідея Люди в thinking: поле для редагування задачі з live update промпту. Прямо закриває H4 і "залежить від задачі" з Q5. Scope-able за 1-2 дні?
4.
Маппінг 5 причин з брифа — кладемо в presentation deck?
