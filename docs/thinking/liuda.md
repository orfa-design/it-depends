## 2026-05-25 — Wireframe v1: флоу і зміни

**Було:** рівень → вибір задачі з меню (9 опцій) → промпт
**Стало:** рівень → біль → доступ → свайп-картки (1 за раз) → промпт → "Я спробувала" → completion

**Чому:**
Перша версія відчувалась як "вибери з меню" — юзер сам вибирає, продукт не персоналізує. Core value prop загубився. Повернулась до оригінального брейнштормового флоу з трьома питаннями + свайпом.

---

**Було:** задачі = "що зробити в Claude" (підсумок, аналіз, FAQ)
**Стало:** задачі = артефакт на виході (шаблон для Notion, system prompt, Figma плагін)

**Чому:**
Старі задачі не давали відчуття "наступного рівня" — це те що вона і так могла спитати в Claude. Нові задачі виробляють щось конкретне: файл, інструмент, скрипт. Відповідає wow-моменту "я зробила річ".

---

**Було:** один CTA "Відкрити в Claude →" для всіх
**Стало:** Claude для text-артефактів, Claude Code для code-артефактів (з інструкцією в терміналі)

**Чому:**
Кнопка "Відкрити в Claude Code →" відкривала claude.ai — брехня. Для code-задач реальний шлях це CLI. Зробила чесно: кнопка копіює промпт + показує покрокову інструкцію.
