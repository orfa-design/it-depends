## Що змінилось у lib/data.ts (структурно)

### 1. `result` і `resultLabel` більше не існують

Старі поля:
```ts
result?: string | null
resultLabel?: string
```

Замінені на масив:
```ts
results?: { url: string; label: string }[]
```

Якщо будеш копіювати або переписувати кроки — використовуй новий формат. TypeScript кине помилку якщо залишиш старий.

### 2. Нове обов'язкове поле `layer: 0 | 1 | 2 | 3 | 4`

Кожен крок тепер має `layer` — рівень складності. Використовується у вигляді "Зв'язки" для вертикального розміщення карточок.

Маппінг:
- `0` — простий чат (foundation)
- `1` — більше можливостей
- `2` — промпт-інженерія
- `3` — код і деплой
- `4` — повний продукт

**Не видаляй це поле** — без нього TypeScript помилка і граф не працює.

## Що безпечно редагувати

Текстові поля — редагуй вільно, структуру не чіпай:
- `title`, `subtitle`, `meta` — у масиві `STEPS`
- `doable`, `technical`, `time`, `taskDefault`, `promptText` — у `STEPS_EXTRA`

## Нові фічі (просто щоб знав)

- **3 режими перегляду:** Шлях / Галерея / Зв'язки (force-directed граф карточок)
- **Галерея** тепер виглядає як карточки з Зв'язків — єдиний стиль
- **Кнопка "пропустити → одразу до галереї"** на стартовому екрані
- **Кілька результатів на крок** — через `results[]` з лейблами
- **Крапки складності (layer)** — видно на кожній карточці в Галереї і Зв'язках
- **Favicon** — символ ≈
