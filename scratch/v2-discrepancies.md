Складено: 2026-06-01. Джерело: порівняння `it-depends-2/project/` (оригінальний HTML-прототип) з `app/v2/`.

## Критичні — впливають на функціональність

**1. `{task}` підстановка не працює**
- Код: `step.prompt.replace('{task}', task)` → `app/v2/step/[id]/page.tsx:126`
- Але всі промпти в `lib/data-v2.ts` містять `[вставити сюди]`, не `{task}`
- Юзер заповнює "Моя задача" — вона нікуди не підставляється. Поле і промпт повністю розʼєднані.
- Фікс: або замінити `[вставити сюди]` на `{task}` в промптах, або змінити логіку підстановки.

**2. Calibration reaction 3 — "out" label захардкоджений від старої логіки**
- Файл: `app/v2/calibrate/page.tsx:193` → `out: "у мене є"` (залишок від оригіналу)
- Оригінал: 3-тя реакція = "Я вже щось схоже роблю" → `out: "у мене є"` — логічно
- V2: 3-тя реакція = "Не цікаво" (`skip`), але `out` залишився "у мене є" — юзер бачить протиріччя
- Фікс: змінити на `out: "не моє"` або прибрати `out` для skip.

**3. Recommendation engine — семантика `skip` перевернута**
- Файл: `app/v2/V2DataContext.tsx:284` → `skip → -2` до score категорії
- Оригінал: 3-тя реакція = "вже вмію" → мала б або підіймати score, або ігноруватись
- V2: `skip` = "не цікаво" → -2 — це нова семантика, але recommendation logic написана під стару
- Результат: карта після калібровки може показувати протилежне від корисного
- Потребує обговорення: чи правильно що `skip` = "не рекомендувати категорію"?

**4. "Пропустити" → не на галерею**
- Файл: `app/v2/calibrate/page.tsx:52` → redirect на `/v2/map`
- Кнопка каже: "пропустити → одразу до галереї", але веде на Map
- Фікс: змінити redirect на `/v2/gallery` або змінити текст кнопки.

## UX — помітні різниці в поведінці

**5. Build phases — немає per-phase task поля**
- Оригінал: кожна фаза має власний `<textarea defaultValue={phase.task}>`
- V2: тільки одна глобальна "Моя задача" на весь крок
- При build-кроці з 3 різними інструментами юзер змушений вручну переписувати контекст у кожній фазі

**6. MapStrip — subtitle при `avail` стані зник**
- Оригінал: крок зі статусом `avail` показує `"можна почати"` як subtitle
- V2: завжди показує `s.subtitle` — орієнтир "можна почати" зник
- Файл: `app/v2/step/[id]/page.tsx:156`

**7. MapOverview — відсутній stats блок**
- Оригінал: три лічильники (пройдено / можна почати / усього)
- V2: тільки текст і кнопка "Перебудувати маршрут"
- Файл: `app/v2/map/page.tsx:86`

**8. Phase toggle — немає `+` / `−` індикатора**
- Оригінал: `<span className="phase-pm">{open ? "−" : "+"}</span>` в хедері фази
- V2: немає аналогу — юзер не бачить візуально що фазу можна розкрити/згорнути

**9. Done page — навігація не відкриває виконаний крок**
- Оригінал: "на мапу" → `setTab("path"); setSel(step.id)` — відкриває Map і виділяє виконаний крок
- V2: → `/v2/map` без виділення кроку
- Файл: `app/v2/step/[id]/done/page.tsx:39`

## Відсутні фічі зі специфікації

**10. Gallery — немає секції "Для тебе"**

- V2: `GalleryView` (`app/v2/V2ClientApp.tsx:940`) — секції немає

- Spec: технічна кнопка в хедері
- V2: схована за ⚙️ TweaksPanel (`app/v2/V2AppShell.tsx:194`)

**13. `levelUp` vs `nextPath` — два паралельних поля**
- Spec: поле `levelUp[]` (масив рядків)
- `lib/data-v2.ts`: дані містять `nextPath` (HTML-рядок) — старе поле з оригіналу
- Сторінка кроку рендерить обидва: `app/v2/step/[id]/page.tsx:355`
- Нові кроки через AddStepModal зберігають `levelUp[]`, старі — `nextPath`

## Дрібні але помітні

**14. `doable` поле де-факто дублює `subtitle`**
- `app/v2/V2ClientApp.tsx:1568`: `doable: formData.subtitle` при створенні кроку
- Картки галереї показують `s.doable` (рядок 1028) — для нових кроків = subtitle, для старих — окремий текст

**15. Calibration: 4 картки в даних, але eyebrow каже "4 кейси" а показує 3**
- `CALIBRATION_CARDS.length` = 4 (anya, masha, daryna, olena)
- `history.length >= 3` завершує калібровку після 3 карток
- Eyebrow: "· 4 кейси" — невідповідність

**16. "не цікаво" більше не скидається при перемиканні кроку**
- Оригінал: `useEffect(() => setNotInterested(false), [step.id])` — завжди скидалось
- V2: персистується в KV (за spec), але відчуття відрізняється від оригіналу
